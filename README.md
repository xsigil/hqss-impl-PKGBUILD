# hqss-impl-PKGBUILD

Arch Linux PKGBUILD for [hqss-impl](https://github.com/xsigil/hqss-impl) (MONOLITH Protocol HQSS-v4 Universal Provisioning & Reconstruction Tools).

## Installation

```bash
git clone [https://github.com/xsigil/hqss-impl-PKGBUILD.git](https://github.com/xsigil/hqss-impl-PKGBUILD.git)
cd hqss-impl-PKGBUILD
makepkg -si

```

## Binary Installed

* `/usr/bin/hqss-gen`
* `/usr/bin/hqss-restore`
